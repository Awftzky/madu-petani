# madu-petani

`madu-petani` is a product branding website for MADU PETANI, an Indonesian UMKM that promotes and sells honey sourced or supplied from Sulawesi.

## Project Goals

- Establish MADU PETANI's online brand presence.
- Present clear product and business information.
- Provide a simple path for customers to contact the business or begin an order.
- Remain easy to understand and extend throughout a Web Development course.

## Current Development Phase

The project is currently in the Tailwind CSS phase. The existing HTML pages use Tailwind utility classes for a consistent, responsive presentation.

## Planned Pages

- Home
- Products
- Product Detail
- Order / Contact

## Technology Status

The project uses semantic HTML, Tailwind CSS through the official Play CDN, and one external stylesheet, `style.css`, for shared base styles. Tailwind utility classes style the navigation, page layouts, product cards, buttons, and form controls, including responsive layouts for narrow screens. The Play CDN requires an internet connection and is intended for development. No custom application JavaScript, React, Bootstrap, backend services, databases, APIs, package manager, or local build tools are in use.

## Development Note

Development will progress in small course-appropriate steps. Future technologies should be introduced only when required, following YAGNI, KISS, and Good Enough Software principles.
